## Added
* Find similar photos in the library using an image selected from a file
* Show the number of selected photos in the gallery
* Exit photo selection mode with the Escape key

## Improvements
* Improved startup responsiveness 
* Improved opening speed for large folders

## Fixes
* Recreate missing thumbnail files so affected photos can appear in the gallery
* Prevent Ctrl+A from selecting gallery photos while viewing a photo
* Layout in grid header for selecting multiple photos in similar search results
