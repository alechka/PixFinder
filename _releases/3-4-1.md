## Added:
* Sort search results by similarity, date added, date created, date modified, name or file size
* Remember the sort order when browsing folders

## Improvements:
* Show hover and pressed states on gallery header dropdowns

## Fixes:
* Keep the photo viewer in the same order as the gallery after changing the sort
* Prevent crashes in some cases in  justified gallery layout
* Fixed crashes on updating photos with duplicate IDs in the gallery
* Handle errors when removing  library folder
* Support semicolons in the library database path
